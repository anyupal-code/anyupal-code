# Andrey Pavlov

Преподаватель программирования и информатики. Разрабатываю учебные курсы по принципу «теория — практика — задания».

## Дисциплины и направления

* **Подготовка к ЕГЭ по информатике** (Python).
* **Основы программирования** (Pascal, C++).
* **Промышленная разработка** (Java, Python, Go).
* **Инфраструктура и DevOps** (Linux, Docker, CI/CD, Kubernetes).

## Учебные курсы

Каждый курс содержит теоретический материал, примеры запускаемого кода и практические задания для самостоятельной работы.

### Java
* [Java Basics Course](https://github.com/anyupal-code/java-basics-course) — основы языка Java для начинающих.
* [Java Backend Course](https://github.com/anyupal-code/java-backend-course) — бэкенд-разработка на Spring Boot, работа с БД и Docker.

### Python
* [Python для ЕГЭ](https://github.com/anyupal-code/python-ege) — решение задач ЕГЭ по информатике на Python.
* [Python Basics](https://github.com/anyupal-code/python-basics) — курс по программированию на Python для начинающих.
* [Python Advanced](https://github.com/anyupal-code/python-advanced) — продвинутый курс Python: типизация, асинхронность, тесты, FastAPI и SQLAlchemy.

### C++
* [C++ Basics](https://github.com/anyupal-code/cpp-basics) — курс C++ для начинающих (22 урока).
* [C++ University](https://github.com/anyupal-code/cpp-university) — университетский курс по C++ (28 уроков).
* [C++ OOP](https://github.com/anyupal-code/cpp-oop) — учебный курс по ООП в C++ с мини-проектом.
* [C++ Algorithms](https://github.com/anyupal-code/cpp-algorithms) — решения 15 учебных задач по C++23.
* [C++ Labs](https://github.com/anyupal-code/cpp-labs) — учебные лабораторные работы.

### Go
* [Go University](https://github.com/anyupal-code/go-university) — курс по Golang: от основ до горутин и тестов.

### Pascal
* [Pascal Basics](https://github.com/anyupal-code/pascal-basics) — основы программирования на Pascal (10 уроков).
* [Pascal Advanced](https://github.com/anyupal-code/pascal-advanced) — продвинутый курс Pascal: ООП, коллекции, алгоритмы.

### DevOps
* [DevOps University](https://github.com/anyupal-code/devops-university) — администрирование Linux, сети, CI/CD и мониторинг.

## Методический подход

1. Сначала разбираем, как технология работает «под капотом» (теоретический блок).
2. Затем смотрим на рабочий пример кода.
3. Закрепляем материал через практические задания.
